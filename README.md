I made this on arch but i used github actions to make executables for 3 OS. The linux version doesn't work on my computer as the executable is for ubuntu but window and mac should work

**Linux/Mac**: download from release and open terminal where you downlade
```
chmod +x MyApp-(linux/Mac)  # see your file name since there is diff name for diff os
.\Myapp(linux/Mac)
```

Windows: Open terminal where your file downloaded

```
.\MyApp-windows.exe
```
